# SPACE INVADERS 1980

1980年代のアーケードゲーム「スペースインベーダー」と同仕様のHTML5 Canvasゲームです。

## 遊び方

1. [index.html](index.html) をブラウザで開くだけで遊べます。
2. タイトル画面で **SPACEキー** または **クリック** で開始します。
3. 操作
   - **← / →** : 自機を左右に移動
   - **SPACE** : レーザー発射
   - **S** : 効果音の ON / OFF 切替
4. エイリアンを全滅させると次のウェーブへ進みます。
5. 自機が弾に当たるか、エイリアンが防衛ラインまで降りてくるとゲームオーバーです。

## ファイル構成

- [index.html](index.html) - ゲーム画面のHTML
- [style.css](style.css) - レトロな見た目のスタイル
- [game.js](game.js) - ゲーム本体のロジック
- [.github/copilot-instructions.md](.github/copilot-instructions.md) - ワークスペース指示

## 主な仕様

- 11列 × 5行 のエイリアン編隊
- 3種類のエイリアン（上段30点、中段20点、下段10点）
- 謎の宇宙船（UFO）出現でボーナススコア
- エイリアンは左右移動し、端に達すると一斉に下降
- 残機制（初期3機）
- ピクセルアート風グラフィック

## 動作環境

モダンなWebブラウザ（Chrome、Firefox、Safari、Edgeなど）で動作します。
